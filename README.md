# Nitish Ch Singha — Video Editor & Motion Specialist Portfolio

An interactive, high-performance 3D Video Editing Portfolio built for **Nitish Ch Singha** (B.Tech 4th Year CSE & Motion Graphics Specialist).

## 🚀 Key Features

- 🎥 **Dynamic Showcase Gallery**: Embedded YouTube, Instagram Reel, and Facebook video playback with category filtering and custom layout views.
- 🎨 **Color Grading Before/After Slider**: Interactive visual comparison tool for RAW LOG footage vs. final DaVinci Resolve color grade.
- 🎛️ **Timeline DAW Simulator**: Interactive multi-track editing timeline showing video cuts, motion graphics overlays, and audio FX layers.
- 💻 **Computer Science & Video Synergy**: Showcase of AE Expression scripting, Python automated video rendering, and FFmpeg workflows.
- 🛡️ **Passcode-Protected Admin Panel**: Comprehensive database management panel for adding, editing, and deleting portfolio projects.
- 💾 **Dual Database Engine**: Synchronizes dynamically with MongoDB Atlas with fallback local persistent JSON database storage.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Three.js, Motion, Tailwind CSS v4, Lucide React
- **Backend**: Node.js, Express, Mongoose (MongoDB Atlas integration)
- **Build Tool**: Vite, `tsx` server execution
